Número virtual para Telegram

O Telegram é um dos serviços mais estáveis para número virtual: o código costuma chegar em segundos e o estoque é grande. O cuidado principal é a senha de duas etapas, que o Telegram pede em conta já existente e que nenhum SMS resolve.

O Telegram trata número virtual com muito menos atrito que o WhatsApp. O estoque é grande, o código chega rápido e o preço fica bem abaixo. É o serviço que costumamos indicar para quem está testando como isso funciona pela primeira vez.

Vale uma diferença importante: o Telegram entrega o código de duas maneiras. Se você já tem o aplicativo aberto em outro aparelho, ele manda o código pelo próprio Telegram, e não por SMS. Como aqui você só tem o número, e não o aparelho, isso só te alcança quando o envio sai mesmo por mensagem de texto — o que acontece em cadastro novo.

O que costuma dar errado

  • Conta antiga com senha de duas etapas: o SMS chega, você digita, e o Telegram pede uma senha que só o dono da conta tem. Nenhum serviço de SMS resolve isso.
  • Pedir código muitas vezes seguidas: o Telegram passa a impor espera crescente. Se falhou, troque de número em vez de insistir.
  • Escolher a opção de ligação: o número recebe texto, não chamada.

Perguntas frequentes sobre Telegram

O código do Telegram demora?

Em geral chega em poucos segundos, e é dos mais rápidos do catálogo. Se passar de dois ou três minutos, provavelmente o Telegram mandou pelo aplicativo em vez de SMS: cancele e receba o valor de volta.

Consigo manter a conta depois?

Enquanto você não sair dela, sim — o Telegram mantém a sessão aberta. Mas se você sair ou trocar de aparelho, vai precisar do número de novo, e ele não será mais seu. Para conta que você quer manter, use um chip próprio.

Dá para usar em bot?

Bot do Telegram não precisa de número: ele é criado pelo BotFather a partir de uma conta que já existe. Número virtual é para criar a conta, não o bot.

Quer testar?

Criar a conta é de graça. Você só coloca saldo quando for pedir o primeiro número, a partir de R$ 5,00 por PIX.
